Trial entry tools

The interfaces on this page automate and simplify the process of taking downloaded trial entries and extracting the data you need in formats that you can use. The spreadsheet tools give your file back with new tabs added, so you can run them one after another on the same file. The final step produces the various formats of running orders in Word, and the judges' score sheets as a PDF, that you may want to use for your trial.

IMPORTANT - trial lists are produced in a random order. If you wish to move people around, you should do that manually before proceeding to step 4. Remember to move the entire line. Also, if you want to change the running order for different elements, duplicate the entire tab and reorder them there.

The tools, in the usual order

  1. 1

    Payment Split

    Splits entries into Paid, Part Paid and Not Paid tabs and shows who still owes, and how much.

    Adds: Paid · Part Paid · Not Paid tabs

    Open →
  2. 2

    Email List

    Makes one email address per person, ready to paste into BCC. Run it on a Payment Split file to email just one group.

    Adds: Emails tab · BCC list

    Open →
  3. 3

    Trial Lists

    Makes a randomly ordered running list for each trial (e.g. NWAdv1), with D / H reactivity flags and a check for handlers with two dogs in one trial.

    Adds: One tab per trial

    Open →
  4. 4

    Trial Documents

    Turns the trial tabs into Word documents (A4): running orders for the catalogue, callboards, and timekeepers' and judges' sheets with one element and judge per sheet. It also prints the judges' score sheets as a PDF, one per dog for each search, with the date, host, judge, element, search time and running-order number filled in. Wherever possible data need only be entered once, however there are plenty of customisation options too, including the possibility of adding your logo.

    Makes: Running orders · Callboards · Timekeepers · Judges (.docx) · Score sheets (.pdf)

    Open →

You don't have to use every tool. Steps 1–3 each work on their own with an entries download; Trial Documents needs the file from Trial Lists.

Good to know

  • Using Google Sheets? Choose File → Download → Microsoft Excel (.xlsx), drop that into a tool, then bring the result back with File → Import.
  • Old .xls files aren't supported. Open them in Excel and use Save As → Excel Workbook (.xlsx) first.
  • Chaining tools: each tool's download keeps all your tabs, so drop it straight into the next tool.
  • Needs internet to load the page. The work itself happens on your computer.
