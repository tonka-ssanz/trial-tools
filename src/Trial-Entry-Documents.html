            Good to know

            • Row order is never changed. Each table lists the dogs exactly as they appear on the tab.
            • Numbers are added for you: each table is numbered 1, 2, 3… in the order the dogs appear on the tab.
            • Reactive dogs: the Reactive column shows D (dogs), H (humans) or D + H, and the whole row is printed in bold red.
            • Level names are filled in from the tab name (NWAdv1 → Advanced, BHNovS1 → BH Novice Sand). The trial number is kept when a level appears more than once. You can type over any of them.
            • Organisation, venue and Trial # aren't printed on these documents. They're saved with your trial for the Results Sheets step, which fills them in on the SSANZ results spreadsheets so they don't have to be typed there. Choose your organisation from the list once (it comes from the SSANZ organisations page; if yours isn't there, choose “Not in the list” and type it). Give each class its venue (trials on different days are often at different venues) and its Trial #, copied from the left-hand column of the SSANZ events page, e.g. NWAdvCS1: DF10262 → DF10262. Each class has its own Trial #.
            • One setup, several documents: level, date, session, venue and Trial # are entered once and used by every document. Which classes are ticked, the order and the copies are kept separately for each document, so you can print just one or two callboards without changing the catalogue.
            • Catalogue running orders: each table is kept in one piece, and tables share a page when they fit. A table too long for one page starts on a new page and carries on over the next, with the heading row repeated. The preview's page numbers are a close estimate; Word makes the final fit.
            • Callboards: each class starts on its own page, with larger text and a Started ✓ column to tick. Set Copies to print more than one. Each copy can have an element line under the title: pick elements from the list in the order they run (each one is added to the end), then edit the text to add numbers such as “Exterior 2”. Or choose Other and type exactly what should be printed (up to one line). If nothing is chosen or typed, a line to write on is printed instead.
            • Timekeepers and Judges: one sheet per search, up to 8 per class. Choose each search's element from the list, or choose Other and type it. An element used twice in a class is numbered for you (Exterior 1, Exterior 2). The judge's name prints on the right of the element line; leave it blank to write it in. Every search needs an element before the sheets download. Timekeepers, Judges and the judging sheets share the same searches, so you only fill them in once.
            • Judging sheets: one sheet per dog for each search, with the date, host, judge, element, search time and the dog's running-order number filled in. They use the same searches (copies), elements and judges as the Timekeepers and Judges sheets. Standard searches sets up the usual searches for the class in one click. Search times come from the regulations; where the judge sets the time on the day, the range is printed. If you type an element under Other, a usual one (e.g. “Interior 2”) gets the regulation time for the class; anything else asks you for its time in minutes.
            • Spare judging sheets: choose 0–9 for each class, a few for a small class and more for a big one. The judging sheets won't download until every class has a number.
            • Excellent hides: choose the number of hides for each search. The judging sheets won't download until they match the numbers drawn for the trial (3, 3, 3, 2 and 1).
            • Coloured paper for each element: the usual colours are filled in (Containers yellow, Interior pink, Exterior blue, Vehicle green); change any of them once and they're saved with your trial. Then use the buttons under the download, one per element: load that colour of paper, print, and move on to the next. The Download button still gives every element in one file.
            • Certificates: one for every dog entered in each ticked class, in alphabetical order of handler. Withdrawn dogs are already off the trial tabs, so they don't get one. The handler, dog, date (e.g. 2 November 2026) and host club are printed in a handwriting-style font onto the pre-printed SSANZ A5 card; points, times, title YES / NO and signatures are written on the day. A dog in NWAdv1 and NWAdv2 gets two.
            • Printing certificates: first print the test page on plain paper cut to A5 (an A4 sheet cut in half), the same way you'll print the cards: paper size A5, landscape, actual size (100%, not “Fit to page”). Before printing, pencil a small X in one corner of the side facing up, so you know which way round to load the cards. Lay the test on a card and hold both up to a window: the grey lines should sit on the card's lines. If not, measure the gap and use Move right / Move down. Card usually goes in the manual (bypass) tray. If your printer can't take card, the certificates can still be handwritten.
            • Printing judging sheets: print at actual size (100%, not “Fit to page”) and single-sided, so the cut line stays in the middle of the page.
            • Don't re-run Trial Lists once the running orders are out: it shuffles the order again and every number would change. Use the spare sheets for late changes.
            • Save progress puts everything you've entered on this page (dates, levels, searches, judges, logo, host and the rest) into your trial spreadsheet and downloads it. Drop that file in next time and everything comes back. Documents download on their own, so save progress before you close the page; the page reminds you when there are unsaved changes.
            • Locking: the first time you save progress, the Master List and trial tabs are locked so the documents stay right. To change entries after that, use Make a late change in Trial Lists. When you come back here, the page lists the classes that changed and which documents to reprint.
            • Your own copies of a trial tab (e.g. “NWAdv1 Sat plan”) can be ticked like any other class. They use the same class settings as the trial they came from.
            • Edit your trial spreadsheet in Excel or free Excel for the web (excel.cloud.microsoft). After editing in Excel for the web, use File → Save As → Download a copy. Keep the file for at least 12 months, stored securely and not on a shared computer.
            • Google Docs can open the downloaded .docx too (File → Open → Upload).
            • The file never leaves your computer. All the work happens in this page.
