    Good to know

    • Row order is never changed. Each table lists the dogs exactly as they appear on the tab.
    • Numbers are added for you: each table is numbered 1, 2, 3… in the order the dogs appear on the tab.
    • Reactive dogs: the Reactive column shows D (dogs), H (humans) or D + H, and the whole row is printed in bold red.
    • Level names are filled in from the tab name (NWAdv1 → Advanced, BHNovS1 → BH Novice Sand). The trial number is kept when a level appears more than once. You can type over any of them.
    • One setup, several documents: level, date and session are entered once and used by every document. Which classes are ticked, the order and the copies are kept separately for each document, so you can print just one or two callboards without changing the catalogue.
    • Catalogue running orders: each table is kept in one piece, and tables share a page when they fit. A table too long for one page starts on a new page and carries on over the next, with the heading row repeated. The preview's page numbers are a close estimate; Word makes the final fit.
    • Callboards: each class starts on its own page, with larger text and a Started ✓ column to tick. Set Copies to print more than one. Each copy can have an element line under the title: pick elements from the list in the order they run (each one is added to the end), then edit the text to add numbers such as “Exterior 2”. Or choose Other and type exactly what should be printed (up to one line). If nothing is chosen or typed, a line to write on is printed instead.
    • Timekeepers and Judges: one sheet per element, up to 8 per class. Each copy has one element (pick it, then add a number if needed, e.g. “Exterior 2”) and the judge's name, printed on the right of the element line. Leave either blank to write it in. The two documents share the same copies, elements and judges, so you only fill them in once.
    • The logo isn't remembered, so choose it again each time you use the page.
    • Google Docs can open the downloaded .docx too (File → Open → Upload).
    • The file never leaves your computer. All the work happens in this page.
