              Good to know

              • Your trial spreadsheet is one file you keep adding to. Each download ends in “(in progress)”. Always drop the newest one back in.
              • Sheet 1 is the website download, exactly as downloaded. It's locked: you can see and copy it, but not type in it.
              • Make changes on the Master List: add a late entry as a new row (leave Entry ID blank and put x in its trial columns), type Withdrawn in Status to withdraw an entry from the whole event (the row turns grey and struck through), delete an x to scratch it from one trial, or correct a name. Then drop the file back in here and choose Update trial tabs.
              • On the trial tabs you can move rows to change the running order, and duplicate a tab to try another order. Start a copy's name with the trial code, e.g. “NWAdv1 Sat plan”. Names and other details typed on a trial tab are replaced by the Master List on update, and you'll be shown what changes first.
              • Changes made on a trial tab are spotted when you drop the file back in: a row deleted from a trial, a dog moved or copied to another trial, or a new row typed in. You'll be asked about each one, for example “E196 (Jane Smith & Moss) has been removed from NWAdv1. Have they withdrawn from this trial?”. Answer Yes and the Master List is updated to match (changed cells are highlighted yellow; someone left in no trial is marked Withdrawn; a late entry gets its own Entry ID). Answer No and you're asked to check the file first.
              • Copies of a trial tab (for a different running order, e.g. when elements run separately) must have exactly the same entrants as the trial's main tab, just in a different order. If a dog is missing from, or extra on, some of them, you'll be asked about it in the same way, and on Yes every tab for that trial is updated to match.
              • Entry IDs (E014, L001…) link each entry across the tabs. Messages always show the handler and dog too, e.g. “E014 (Jane Smith & Moss)”. Don't change or delete the IDs; when you copy or move a dog to another trial tab, copy the whole row including its ID.
              • Rows start in random order, shuffled separately for each tab, so a dog entered in two trials will usually be in a different spot on each.
              • Comments: trial tabs show only reactivity: D dog-reactive, H people-reactive, D + H both. Check the Master List for other requests.
              • Tool Settings holds what the tools need to carry on where you left off. Please don't edit or delete it.
              • Once Trial Documents has started, the Master List and trial tabs are locked. To change entries after that, drop the file in here and choose Make a late change.
              • Edit your trial spreadsheet in Excel or free Excel for the web (excel.cloud.microsoft). After editing in Excel for the web, use File → Save As → Download a copy. Keep the file for at least 12 months, stored securely and not on a shared computer.
              • The file never leaves your computer. All the work happens in this page.
