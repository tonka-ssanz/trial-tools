    Good to know

    • Which tabs are made: one for every trial column with something entered in it (class name plus trial number, like NWAdv1 or BHNovS2). Empty trial columns get no tab. Tabs are named exactly as the column heading and appear in the same order as the columns.
    • Rows are in random order, shuffled separately for each tab, so a dog entered in two trials will usually be in a different spot on each. Every run gives a new order, and the preview shows exactly what you'll download. For a different draw, just drop the file in again.
    • Handler with two dogs in one trial? That shouldn't happen, so the page shows a warning naming the handler, their dogs and the tab. The lists aren't changed; fix the entry and run the tool again if needed.
    • Comments: only reactivity is carried across. “Reactive to dogs” becomes D, “Reactive to people” becomes H, both become D + H. Everything else (the colons, “Edited …” notes and any other messages) is left out, so check the original Comments column for special requests.
    • Using Google Sheets? In your sheet choose File → Download → Microsoft Excel (.xlsx), drop that file here, then open the result in Google Sheets with File → Import.
    • Several tabs? The tool looks for the tab with Handler, Dog Pet Name and trial columns. If more than one tab has them, you'll be asked which to use. Paid / Part Paid / Not Paid tabs from the Payment Split tool are ignored. All your tabs come back in the download.
    • Running it again on a file that already has these tabs replaces them rather than adding more.
    • The file never leaves your computer. All the work happens in this page.
