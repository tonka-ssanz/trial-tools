Good to know

  • Using Google Sheets? In your sheet choose File → Download → Microsoft Excel (.xlsx), drop that file here, then open the result in Google Sheets with File → Import.
  • Duplicates are matched ignoring capitals and stray spaces, so Jo@Mail.com and jo@mail.com count as one person.
  • Same email, different names (e.g. a couple sharing an address) are kept as one row with both names, like “Sam Lee / Alex Lee”.
  • Several tabs? The tool finds the tab with the “Entry Email” column. If more than one tab has it, you'll be asked which to use. All your tabs come back in the download.
  • Running it again on a file that already has an Emails tab replaces that tab rather than adding another.
  • The file never leaves your computer. All the work happens in this page.
