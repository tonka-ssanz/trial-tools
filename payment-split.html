Good to know

  • How “paid” is decided: an entry with nothing in Amount Due (zero or less) is Paid. If it still owes money and something has been paid, it's Part Paid. If nothing has been paid, it's Not Paid.
  • Blank Amount Due? The tool works it out as Total Cost minus Paid. If it can't, the entry goes in Not Paid so it gets checked, and you'll see a note above.
  • Run this before the Email List tool if you want to email just the people who owe. Drop the downloaded file into the Email List tool and pick the Not Paid or Part Paid tab when it asks.
  • Using Google Sheets? In your sheet choose File → Download → Microsoft Excel (.xlsx), drop that file here, then open the result in Google Sheets with File → Import.
  • Several tabs? The tool finds the tab with the “Amount Due” column. If more than one tab has it, you'll be asked which to use. All your tabs come back in the download.
  • Running it again on a file that already has these tabs replaces them rather than adding more.
  • The file never leaves your computer. All the work happens in this page.
